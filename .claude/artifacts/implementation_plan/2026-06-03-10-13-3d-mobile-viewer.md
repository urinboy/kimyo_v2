## Maqsad

Backendda tayyor 3D modullar moduli (GLB/GLTF) ni Flutter mobile ilovada ko'rsatish. Hozirgi holat: backend CRUD, admin panel, `models3d:import` command bor, lekin **mobil tarafda viewer yo'q** — fayllar serverda yotibdi, o'quvchi ko'ra olmaydi.

## Qamrov

## Entity dizayni

```dart
class ThreeDModelEntity extends Equatable {
  final int id;
  final String slug;
  final String? modelUrl;      // GLB/GLTF to'liq URL (null = faqat info)
  final int? elementId;
  final ElementRef? element;   // {id, symbol, atomicNumber}
  final int sortOrder;
  final String? name;
  final String? description;

  bool get hasModel => modelUrl != null && modelUrl!.isNotEmpty;
  bool get isGlb => modelUrl?.toLowerCase().endsWith('.glb') ?? false;
}
```

`ElementRef` — alohida `lib/domain/entities/element_ref.dart` (kichik value object).

## Viewer UX

**List page (ThreeDModelsPage):**
- AppBar `context.tr('menu_3d_models')`
- GridView 2 col, glass card
- Har kartada: thumbnail (agar image URL bo'lsa) yoki 3D preview placeholder, nomi, element symbol
- Empty state: `context.tr('three_d_models_empty')`
- Loading: CircularProgressIndicator
- Error: retry button

**Detail page (ThreeDModelDetailPage):**
- AppBar — model nomi
- ModelViewer widget (16:9 aspect):
  - `src`: modelUrl
  - `autoRotate: true`
  - `cameraControls: true`
  - `disableZoom: false`
  - `ar: true` (mobile AR)
  - `arScale: auto`
- Pastda: name (h1), description (markdown), element chip

## Risklar

| Risk | Yechim |
|------|--------|
| `model_viewer_plus` Android 21+ talab qiladi | pubspec min_sdk 21 ✓ (allaqachon shunday) |
| Web platform WebView 2 talab qilishi mumkin | Default `kIsWeb` uchun `HtmlElementView` ishlatadi — Chrome 67+ |
| CORS — model_url `storage/3d-models/` dan keladi, public disk | `api.key` middleware public storage'ga ruxsat bermaydi; **tekshirish kerak** |
| GLB katta bo'lishi mumkin (100MB gacha) | Loading state + progress ko'rsatish (ModelViewer o'zi hal qiladi) |
| Locale almashtirganda model qayta yuklanishi kerak | State'da `langCode` saqlanadi, initState'da load |
